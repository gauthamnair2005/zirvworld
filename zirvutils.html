zirvutils provides the standard MOSIX system utilities — standalone command-line programs that ship with every MOSIX distribution. Each is a statically linked, freestanding, no-pie ELF64 binary embedded into the kernel and launched via execve().

Build

make

Produces 18 .elf binaries. All linked against zirvlibc. Embedded into the kernel via init_bin.asm and executed through the kernel's execve save/restore mechanism.
