1. Overview

Zirvium is the reference implementation of the MOSIX standard. This guide covers building and using Zirvium itself, but the same principles apply to any MOSIX-compliant OS.

The user-facing system: Kernel (zirvium) → Init (zirvinit, PID 1) → Shell (zirvshell, 20 commands) → Utilities (zirvutils, 18 programs). Optional: DisplayJet (encrypted display driver), ZirvFlux (display framework), ZirvTK (GUI toolkit), ZirvUI (desktop compositor).

2. Building the OS

# Install dependencies (Ubuntu/Debian)
sudo apt install build-essential nasm grub-pc-bin grub-common \
                 xorriso mtools qemu-system-x86

git clone https://github.com/gauthamnair2005/zirvium.git
cd zirvium
git submodule update --init --recursive
make run

12. FAQ

Is MOSIX related to the historical MOSIX distributed OS?

No. The name is reused, but MOSIX (Modern OSIX) is a new operating system standard designed alongside the Zirvium kernel.

Can I build my own MOSIX OS?

Yes. The MOSIX standard is an open specification. You can write your own kernel, libc, and userspace — as long as they follow the filesystem hierarchy, /zirv namespace, and syscall ABI. See the Distributions page for details.

What hardware does Zirvium support?

x86-64 CPUs with long mode, PCI bus, SATA (ATA PIO), NVMe, USB mass storage, PS/2 keyboard, Synaptics touchpad, serial UART, VGA text mode, pixel framebuffer, Bochs VGA, VMware SVGA, Intel i915 UHD (Gen 9.5-14), NVIDIA GPUs (Enveediya, nouveau port RTX/B-series), Intel Arc GPU (A/B/C-series), AMD Radeon GPU (GCN/RDNA 1–3.5), HDA audio, Intel e1000, VirtIO net/block, RTL8139, Realtek RTL8723DE WiFi, Realtek Bluetooth, TPM 2.0, xHCI USB 3.0, Thunderbolt 3/4 & USB4, WiFi 7 802.11be (Intel BE200, MediaTek MT7927, Qualcomm QCNCM865, Broadcom BCM4389).

How do I reboot or shut down?

Type reboot (ACPI reset via 0xCF9) or shutdown (QEMU exit port 0x604 / Bochs 0xB004) at the shell prompt.
