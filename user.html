1. Overview

Zirvium is an x86-64 operating system that implements the MOSIX (Modern OSIX) standard. It boots on bare metal hardware and in emulators like QEMU.

The user-facing system consists of four layers:

  • Kernel (zirvium) — Handles hardware, memory, processes, and drivers
  • Init (zirvinit) — PID 1, displays boot banner and launches the shell
  • Shell (zirvshell) — Command-line interface with English-like syntax
  • Utilities (zirvutils) — 17 standalone command-line programs

Optional (requires DisplayJet-enabled hardware):

  • DisplayJet (zirvdisplayjet) — MAEM-encrypted display driver
  • ZirvUI (zirvui) — Graphical desktop compositor

2. Building the OS

System requirements

  • A Unix-like system with build tools
  • x86-64-elf cross-compiler (or system gcc)
  • NASM >= 2.14
  • GNU Make
  • grub-mkrescue + xorriso (to create bootable ISO)
  • mtools (to create bootable ISO)

Step-by-step build

# 1. Install dependencies (Ubuntu/Debian)
sudo apt install build-essential nasm grub-pc-bin grub-common \
                 xorriso mtools qemu-system-x86

# 2. Clone the repository
git clone https://github.com/gauthamnair2005/zirvium.git
cd zirvium

# 3. Fetch submodules
git submodule update --init --recursive

# 4. Build and run
make run

3. Running in QEMU

make run builds the ISO and launches QEMU with serial console output in your terminal. You will see the boot banner and eventually the shell prompt / $.

For manual invocation:

qemu-system-x86_64 \
    -cdrom build/zirvium.iso \
    -serial stdio \
    -m 256M \
    -vga std \
    -display sdl

4. Boot Process

  1. GRUB2 loads the kernel from ISO and transfers control
  2. Boot stub (assembly) sets up long mode page tables and enters 64-bit mode
  3. kernel_main initialises 20+ subsystems in order: serial, GDT, IDT, PIC, PMM, VMM, VGA, console, VFS, process table, syscalls, time, PCI, drivers, keyboard
  4. PID 1 (zirvinit) starts in user mode, prints banner, calls execve("/bin/shell")
  5. ZirvShell presents the / $ prompt

5. Using ZirvShell

ZirvShell uses an English-like command syntax alongside standard names:

Basic commands

echo <text> / say <text>Print text to the console
clear / clear the screenClear the terminal screen

Navigation

pwd / wherePrint current working directory
go to <path> / cd <path>Change directory
ls / list / show filesList directory contents via getdents
cat <file> / display <file>Display file contents

System information

unamePrint the operating system name ("Zirvium")
whoamiPrint current user ("root")
show system statusPrint PID, kernel name, and userspace version
datePrint date/time (e.g. "Sun 2024-03-15 14:30:00 UTC+0:00")
settimeSet date/time (YYYY-MM-DD HH:MM:SS)
timezoneShow or set timezone (UTC+/-H:MM)
uptimePrint system uptime (days, hours, minutes, seconds)

Program execution

run <binary>Execute a binary from /bin (replaces shell)
exec <binary>Same as run

System control

rebootReboot the system via ACPI reset (0xCF9)
shutdown / poweroffShut down the system (QEMU/Bochs exit port)
suspendSuspend (not yet implemented)
exitExit the shell

Shell features

  • Line editing: Backspace works for correcting input
  • Quoted arguments: Double quotes for arguments containing spaces
  • Natural language: Multi-word commands like help me please and clear the screen
  • CWD-aware prompt: Always shows the current directory path

7. MOSIX Filesystem

MOSIX replaces the traditional FHS with a simplified layout:

/Root directory
/binSystem binaries (init, shell, all utilities)
/libSystem libraries
/userUser home area (replaces /home, /root)
/bootBoot configuration
/configSystem configuration (replaces /etc)
/zirvDevice namespace (replaces /dev, /sys, /proc, /run)
/mountsMount points (replaces /mnt, /media)
/tmpTemporary files

8. The /zirv Device Namespace

/zirv/sata/SATA (AHCI) storage devices
/zirv/pata/PATA (IDE) storage devices
/zirv/nvme/NVMe SSD devices
/zirv/usb/USB mass storage devices
/zirv/net/Network interfaces (wlan0, bt0, etc.)
/zirv/input/Input devices (keyboard, touchpad)
/zirv/display/Display/graphics devices (gpu0, etc.)
/zirv/tty/Terminal/console devices
/zirv/audio/Audio devices

Console device

The primary console at /zirv/tty/virtual0 aggregates input from PS/2 keyboard and serial port, and outputs simultaneously to VGA text mode, pixel framebuffer, and serial UART. ANSI escape sequences render with VGA attributes and framebuffer pixel colours.

9. Building zirvlibc

cd zirvlibc
make          # produces libzirvlibc.a
make test     # runs unit tests

The test suite verifies string operations (memcpy, memmove, memset, strcmp, strstr), character classification, and printf formatting with all specifiers and zero-padding.

10. DisplayJet & ZirvUI

Zirvium supports a graphical desktop environment via two optional components:

DisplayJet is an in-kernel display driver that provides a compositor-based protocol via 11 custom syscalls (110–120). It drives Bochs VBE-compatible display hardware at 1024x768x32bpp and encrypts all framebuffer surfaces in memory using ChaCha20 (MAEM). Up to 32 surfaces can be created, each with a unique per-surface encryption key derived via HKDF-SHA256.

ZirvUI is a user-space graphical compositor that connects to DisplayJet and renders a complete desktop: procedural background gradient, a 28-pixel top panel with system tray (WiFi, Bluetooth, speaker, battery, user, power icons), a live uptime clock in MM:SS format, and a hamburger menu with "ZirvUI" branding. All text is rendered using a custom 5x7 bitmap font (96 glyphs) with fixed-point cos/sin lookup tables for circular icon geometry.

For full details, see the DisplayJet and ZirvUI documentation pages.

11. Frequently Asked Questions

What is MOSIX?

MOSIX (Modern OSIX) is an operating system standard that replaces legacy paths (/dev, /sys, /proc) with a unified /zirv namespace, simplifies the FHS hierarchy, and drops obsolete interfaces. It is not related to the historical MOSIX distributed OS.

What hardware does Zirvium support?

x86-64 CPUs with long mode, PCI bus, SATA (ATA PIO), NVMe, USB storage (stub), PS/2 keyboard, Synaptics touchpad, serial UART (16550), VGA text mode, pixel framebuffer, Bochs VGA, VMware SVGA, Intel i915 UHD graphics (Gen 9.5-14), NVIDIA GPUs (stub), HDA audio, Intel e1000 NIC, VirtIO net/block, Realtek RTL8139 NIC, Realtek RTL8723DE WiFi, Realtek Bluetooth, and TPM 2.0.

Can I boot Zirvium on real hardware?

Yes. Write build/zirvium.iso to a USB/CD and boot via UEFI/BIOS with GRUB2. Real hardware support is experimental; hardware-specific drivers (AHCI, XHCI) may need additional work.

How do I reboot or shut down?

Type reboot or shutdown at the shell prompt. reboot uses ACPI reset (0xCF9 port) with QEMU/Bochs fallbacks. shutdown writes to the QEMU exit port (0x604) and Bochs exit port (0xB004).

Why is malloc not implemented?

malloc in zirvlibc is a stub returning NULL because the OS does not yet have a fully-featured userspace heap. The brk and mmap syscalls can be used directly.

Does the shell support pipes or redirection?

Not yet. The pipe syscall exists, but the shell does not yet implement | or > syntax.

What is the licence?

Zirvium is licensed under the GNU General Public License v3. Some driver code is derived from Linux and remains under GPL-2.0.

12. Troubleshooting

"Failed to load zirvinit.elf"

The ELF binary may be corrupted. Rebuild with make -C zirvinit clean && make -C zirvinit then rebuild the kernel.

QEMU shows a black screen

Use -serial stdio to see serial output. Try -vga std for Bochs-compatible VBE.

Keyboard input not working

Make sure the QEMU window has focus. The PS/2 driver requires the emulated PS/2 controller (enabled by default).

"mformat not found" when running make iso

Install mtools: sudo apt install mtools (Debian/Ubuntu) or sudo pacman -S mtools (Arch).

"grub-mkrescue: not found"

Install GRUB utilities: sudo apt install grub-pc-bin grub-common xorriso.

Cross-compiler not found

The build falls back to system gcc. Install x86_64-elf-gcc for production builds.

How do I exit the shell?

Type exit. The shell will return and the system will effectively stop (no scheduler to restart).
