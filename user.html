1. Overview

Zirvium is the reference implementation of the MOSIX standard. This guide covers building and using Zirvium itself, but the same principles apply to any MOSIX-compliant OS.

The user-facing system: Kernel (zirvium) → Init (zirvinit, PID 1) → Shell (zirvshell, 20+ commands) → Utilities (zirvutils, 18 programs). Optional: DisplayJet (encrypted display driver), ZirvFlux (display framework), ZirvTK (GUI toolkit with full desktop compositor), ZirvUI (thin compositor stub that runs ZirvTK desktop).

2. Building the OS

# Install dependencies (Ubuntu/Debian)
sudo apt install build-essential nasm grub-pc-bin grub-common \
                 xorriso mtools qemu-system-x86

git clone https://github.com/gauthamnair2005/zirvium.git
cd zirvium
git submodule update --init --recursive
make run

5. Desktop Environment (ZirvTK)

Zirvium features a graphical desktop rendered by the ZirvTK Rust toolkit. When ZirvUI is included in the build, the compositor starts after the shell and presents a dark/neon/glass desktop at 1024x768 resolution.

Desktop layout

  • Background: Vertical gradient (deep navy to near-black) with ambient floating dots
  • Particles: 80 floating ambient particles with per-particle colour cycling and buoyancy physics
  • Clock: Anti-aliased large-scale clock digits (2x bilinear-interpolated bitmap font) with formatted date, powered by real RTC
  • Taskbar: 44-pixel panel at top with 3-dot launcher button and system time
  • App Launcher: Centered modal overlay with "Apps" title and 10 app icons in a 4-column grid. Each app has a unique colour, SVG vector path icon, and animated hover pulse (sinusoidal glow)

Navigation

Click the launcher dot (3-dot icon) in the taskbar to open the app grid. Hover over an icon to see the animated glow pulse. Click an icon to launch. The launcher closes automatically on launch. Currently, the compositor is single-app full-screen — the launcher closes when an app is opened. A "return to desktop" button is provided in-app.

Display Technology

All rendering is scanline-optimised software drawing into a framebuffer. VBE page flipping (Y_OFFSET method) provides tear-free display updates. Hardware cursor is used exclusively (no software cursor).

6. FAQ

Is MOSIX related to the historical MOSIX distributed OS?

No. The name is reused, but MOSIX (Modern OSIX) is a new operating system standard designed alongside the Zirvium kernel.

Can I build my own MOSIX OS?

Yes. The MOSIX standard is an open specification. See the Distributions page for details.

What hardware does Zirvium support?

x86-64 CPUs with long mode, PCI bus, SATA (ATA PIO), NVMe, USB mass storage, PS/2 keyboard, Synaptics touchpad, serial UART, VGA text mode, pixel framebuffer, Bochs VGA, VMware SVGA, Intel i915 UHD (Gen 9.5-14), NVIDIA GPUs (Enveediya, RTX/B-series), Intel Arc GPU (A/B/C-series), AMD Radeon GPU (GCN/RDNA 1–3.5), HDA audio, Intel e1000, VirtIO net/block, RTL8139, Realtek RTL8723DE WiFi, Realtek Bluetooth, TPM 2.0, xHCI USB 3.0, Thunderbolt 3/4 & USB4, WiFi 7 802.11be.

How do I reboot or shut down?

Type reboot (ACPI reset via 0xCF9) or shutdown (QEMU exit port 0x604 / Bochs 0xB004) at the shell prompt.
