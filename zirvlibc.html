zirvlibc is the reference MOSIX C library — a freestanding libc providing the standard C functions and syscall wrappers needed by all MOSIX userspace programs. Any MOSIX-compliant kernel can run programs built against zirvlibc.

The library is designed specifically for the MOSIX x86-64 ABI. All syscall wrappers use the SYSCALL instruction with the convention: RAX = syscall number, RDI–R9 = arguments, return in RAX (negative errno on error).

Build

make          # produces libzirvlibc.a
make test     # builds and runs unit tests

The test suite verifies string operations (memcpy, memmove, memset, strcmp, strstr), character classification, and printf formatting.
