ZirvTK — MOSIX Desktop Toolkit & Widget Library

ZirvTK is the reference MOSIX GUI toolkit — a Rust library with C FFI providing raw framebuffer drawing primitives, a 3D software renderer, and utility widgets. The ZirvUI compositor is now a standalone C application that does its own rendering; ZirvTK serves as an optional drawing library for external programs and demos.

Canvas Rendering

  • Scanline-rounded rects — fill_round_rect and stroke_round_rect use scanline span fills (O(h) per call) instead of per-pixel hit-testing (O(w×h))
  • Gradient fills — fill_gradient_v and clear_gradient for vertical color transitions
  • Anti-aliased text — draw_char_scaled uses bilinear interpolation between source pixels for smooth scaled glyphs
  • Circle fill — integer edge-finding slice fill avoids per-pixel sqrt
  • Alpha blending — full RGBA blend compositing pipeline
  • Vector path icons — SVG-style compact binary path definitions (MoveTo/LineTo) with anti-aliased polygon fill
  • 3D renderer — fixed-point triangle rasterizer with depth buffer, used by demo programs

Implementation

ZirvTK is written in Rust and compiled with #![no_std] for freestanding MOSIX environments. It uses a custom arena allocator (16 MiB pool) when running outside a kernel allocator. The library communicates with the display through the ZirvFlux platform abstraction, which translates draw commands into buffer writes and presentation requests via the DisplayJet kernel driver.

The C FFI layer (c_api.rs + include/zirvtk.h) exposes raw framebuffer drawing functions (ztk_fb_*), vector path icon rendering (ztk_draw_icon_path), and font rendering to C programs. The ZirvUI compositor historically called ztk_desktop_run() to enter the Rust desktop loop, but now uses its own native C renderer instead.

Project Structure

src/
  lib.rs           Crate root, no_std entry point
  allocator.rs     Freestanding arena allocator (16 MiB pool)
  canvas.rs        Software renderer (scanline-optimized)
  c_api.rs         C FFI exports
  color.rs         Color types (RGBA, blend, gradient)
  ffi.rs           ZirvFlux FFI bindings
  font.rs          Bitmap font data
  fx.rs            Visual effects
  obj3d.rs         3D object utilities
  platform.rs      Platform abstraction (DisplayBuffer, events)
  rawfb.rs         Raw framebuffer drawing + vector path icons
  rect.rs          Rectangle geometry
  widget.rs        Widget trait + Event types
include/
  zirvtk.h         C header for FFI

Build

# Standalone (with ZirvFlux dependency)
ZIRVFLUX_DIR=../zirvflux cargo build --release --no-default-features --features alloc

# As submodule in Zirvium
cd /path/to/zirvium/zirvtk
ZIRVFLUX_DIR=../zirvflux cargo build --release --no-default-features --features alloc

Produces libzirvtk.a and libzirvtk.rlib.

Dependencies

  • zirvflux — Display framework
  • libm — Math library (sqrt, sin, cos for effects and rendering)
