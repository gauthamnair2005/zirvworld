ZirvTK is the reference MOSIX GUI toolkit — a Rust widget library with C FFI for building graphical applications on top of the ZirvFlux display framework. It provides a complete widget tree with event propagation and layout management.

Widgets

WidgetDescription
Widget (trait)Base trait: event handling, layout, draw
ButtonClickable button with label
LabelStatic text label
PanelContainer for child widgets
WindowTop-level window with title bar
TileScrollerScrollable grid of media tiles with physics-based scrolling
MediaTileContent tile with thumbnails, labels, and gradients

Features

  • Canvas — software rendering surface with pixel, rect, text drawing
  • 5x7 bitmap font for all text rendering
  • Color, Rect, Font primitives
  • App — application scaffold with platform abstraction
  • C FFI (zirvtk.h) for linking from C/C++ compositors
  • no_std compatible with custom arena allocator for freestanding environments
  • Builds as staticlib, cdylib, and rlib

Implementation

ZirvTK is written in Rust and compiled with #![no_std] for freestanding MOSIX environments. It uses a custom arena allocator when running without a kernel allocator. The library communicates with the display through the ZirvFlux platform abstraction, which translates draw commands into buffer writes and presentation requests via the DisplayJet kernel driver.

The C FFI layer (c_api.rs + include/zirvtk.h) allows C/C++ compositors like ZirvUI to create and manage widgets through a stable C ABI.

Project Structure

src/
  lib.rs           Crate root, no_std entry point
  allocator.rs     Freestanding arena allocator
  app.rs           Application scaffold
  button.rs        Button widget
  canvas.rs        Software renderer
  c_api.rs         C FFI exports
  color.rs         Color types
  ffi.rs           Internal FFI helpers
  font.rs          5x7 bitmap font data
  label.rs         Label widget
  panel.rs         Panel container widget
  platform.rs      Platform abstraction (DisplayBuffer, events)
  rect.rs          Rectangle geometry
  tile.rs          MediaTile widget
  scroller.rs      TileScroller widget
  widget.rs        Widget trait + Event types
  window.rs        Window widget
include/
  zirvtk.h         C header for FFI
examples/
  demo_rust.rs     GUI demo in Rust
  demo_c.c         GUI demo in C (links via C FFI)

Build

cargo build --release

Produces libzirvtk.a, libzirvtk.so, and libzirvtk.rlib.

Dependencies

  • zirvflux — Display framework
  • zirvlibc — C library
