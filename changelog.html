2026

June 2026

ZirvTK Desktop Compositor Overhaul — The desktop compositor has been moved entirely into the ZirvTK Rust toolkit. ZirvUI is now a thin C stub (~30 lines) that initialises ZirvFlux and calls ztk_desktop_run(). All rendering, widgets, input handling, and the compositor loop are in ZirvTK, allowing UI updates to land with only toolkit changes.

Scanline-Optimised Rendering — fill_round_rect and stroke_round_rect now use scanline span fills (O(h) per call) instead of per-pixel hit-testing (O(w×h)), dramatically improving glass panel performance. The glass_panel widget was rewritten to use the scanline API.

Launcher Redesign — Fixed launcher sizing (was too small, apps overflowed). Removed glow_rect from launcher for performance. Added animated hover colour (sinusoidal pulse via sin). Fixed vector path icon assignments with distinct per-app colours. Fixed on_launch callback wiring.

Desktop Aesthetic — New dark/neon/glass theme with gradient background (deep navy to near-black), 80 ambient floating particles with per-particle colour cycling and buoyancy physics, anti-aliased large-scale clock digits (2x bilinear-interpolated bitmap font) with RTC-driven formatted date, 44-pixel taskbar with 3-dot launcher button, and centered app launcher grid with SVG vector path icons.

Performance & Display — Hardware cursor only (no software cursor overhead). VBE page flipping via DisplayJet Y_OFFSET for zero-tearing display. Removed particle glow for additional performance. All 7 ecosystem repos committed and pushed to GitHub.

May 2026

Settings Redesign & Font Options — The Settings app has been redesigned with a tabbed interface (Display / Network / Audio / About), matching the tab-based UI pattern introduced by the Demo app. New settings: wallpaper preset selector (6 gradient schemes: Deep Blue, Twilight, Forest, Sunset, Ocean, Midnight), accent color picker (8 colors: Teal, Blue, Red, Green, Orange, Purple, Mint, Pink), animation speed toggle (Fast / Medium / Smooth), font style toggle (Regular / Bold), and font size toggle (Small / Large). The accent color dynamically updates across the entire UI — taskbar "Zirvium" heading, clock text, settings headers, and the demo app 3D canvas all reflect the current accent.

Bold Font Variant — The 8×13 bitmap font now supports a Bold variant (thickened strokes) computed at runtime from the regular glyph data. Controlled by the Font Style toggle in Settings → Display. No additional storage required.

Demo App — A new 4-tab demonstration app showcasing all ZirvTK capabilities: 2D Shapes (fill_rect, fill_circle, fill_round_rect, draw_line, fill_gradient_v, draw_text), 3D Wireframe (software fixed-point 3D pipeline rendering a colour-cycling cube and an accent-tinted tetrahedron on an accent-coloured canvas), Interactive Widgets (toggle switches, clickable buttons, slider control with live status display), and Icons (all 16 procedural icon types with labels).

Anti-Aliased Font — The toolkit's ztk_fb_draw_char now performs anti-aliased rendering by checking 4 neighbour pixels (left, right, above, below) and blending edge pixels at alpha=180 for smoother font appearance. A separate ztk_fb_draw_char_aa variant was also added with configurable AA level.

Font Data Generation — All font data is now generated by a single Python script (tools/genfont.py) that outputs a C header (font_8x13.h) for the compositor, Rust source (font.rs) for ZirvTK, and a 34 KB TrueType font (zirvium_system.ttf) as a build-time artifact. The improved glyph data provides better readability at 8×13 resolution.

Kernel SSE Support & ELF Loader Fix — Two critical fixes enabling the ZirvTK Rust GUI toolkit in the compositor. The kernel now sets CR4.OSFXSR (bit 9), CR4.OSXMMEXCPT (bit 10), CR0.MP (bit 1), and CR0.NE (bit 5) during boot so SSE/SSE2 instructions (used by Rust's precompiled core library) execute without raising #UD. The ELF loader (kernel/loader/elf.c) now correctly handles PT_LOAD segments with non-page-aligned p_vaddr — the data copy offset within the first page is computed as vaddr & 0xFFF instead of always writing to offset zero. Without this, .data.rel.ro relocations (e.g., the font glyph table pointer) were zeroed, causing a #PF in the compositor.

Multi-Window Compositor — ZirvUI rewritten from a single-app full-screen compositor to a multi-window desktop with a Metro-style tile start screen. Tile click triggers a flip+expand animation (vertical squeeze followed by ease-out expansion to full screen). Each app opens in its own window with a 28-pixel title bar featuring close button (X) with red hover, drag-to-move, window snapping (drag to left/right screen edge for half-screen snap), and chrome auto-hide (Zirvium heading, exit/power buttons hide automatically when a title bar overlaps them).

IPC Message Queues — New kernel IPC subsystem (kernel/ipc/mqueue.c) providing ring-buffer message queues (256 messages × 64 bytes each). Four new syscalls: SYS_MQ_CREATE (140), SYS_MQ_SEND (141), SYS_MQ_RECV (142), SYS_MQ_DESTROY (143). mq_recv blocks the calling process (PROC_STATE_BLOCKED) when the queue is empty; the scheduler skips blocked processes and mq_wake_waiters unblocks them when data arrives.

HPC / MPI Subsystem — New kernel HPC subsystem (kernel/hpc/hpc.c) for inter-process communication and synchronisation. Auto-assigns process ranks on registration. Seven syscalls: SYS_HPC_RANK (144), SYS_HPC_SIZE (145), SYS_HPC_BARRIER (146), SYS_HPC_SEND (147), SYS_HPC_RECV (148), SYS_HPC_BCAST (149), SYS_HPC_REDUCE (150). Barrier synchronisation uses a shared message queue; reduction supports SUM, MAX, and MIN operations.

Audio Subsystem Fixes — Resolved critical synchronization issues in the AC97 driver DMA ring-buffer management. Added missing hardware status tracking (CIV/LVI) and corrected buffer completion interrupt handling for stable 48 kHz stereo playback. Improved driver registration reliability across PCI devices.

ZirvTK GUI Toolkit — New MOSIX GUI toolkit written in Rust with C FFI. Provides widgets (Button, Label, Panel, Window, TileScroller, MediaTile), software Canvas renderer, 5x7 bitmap font, and platform abstraction over ZirvFlux. Builds as staticlib/cdylib/rlib. Includes Rust and C demo applications. (ZirvTK v0.1.0)

ZirvFlux Display Framework — New MOSIX display framework library providing a Mesa-like API for compositors. Abstracts the DisplayJet kernel driver behind a clean compositor-facing interface. (ZirvFlux v0.1.0)

Desktop Improvements — ZirvUI now displays a complete desktop with procedural background gradient, 28-pixel top panel, hamburger menu icon, "ZirvUI" branding, system tray (WiFi, Bluetooth, speaker, battery, user, power icons), and live uptime clock using 5x7 bitmap font.

DisplayJet Encryption — All compositor surfaces now encrypted at rest in kernel memory using ChaCha20 with per-surface keys derived via HKDF-SHA256. Hardware entropy via RDRAND with xorshift64+RDTSC fallback. 11 custom syscalls (110–120) for the compositor protocol.

execve Save/Restore — Kernel now supports automatic caller save/restore during execve, allowing the shell to survive after running external commands. The shell process image is preserved and returns to the prompt after every command.

PCI Enumeration for Userspace — New syscall 103 exposes PCI device enumeration to userspace, enabling the lspci utility. The kernel probes PCI buses during boot and exposes the device tree.

Network Utilities — New ifconfig utility for network interface configuration. Added to zirvutils as the 17th embedded utility.

Earlier 2026

Linux Compat Layer — New linux_compat.h compatibility layer enabling direct porting of Linux kernel drivers to MOSIX. Drivers ported: NVIDIA GPU (Enveediya), Intel Arc GPU, AMD Radeon GPU, VirtIO block/net, RTL8139 NIC, xHCI USB 3.0, Thunderbolt 3/4 & USB4, WiFi 7 (BE200, MT7927, QCNCM865, BCM4389).

DNS Resolver — New syscall 102 provides kernel-level DNS resolution. The kernel performs DNS lookups and returns IP addresses to userspace.

Extended Drivers — Intel i915 UHD display driver (Gen 9.5–14), Enveediya GPU (nouveau port, RTX/B-series), Intel Arc GPU (A/B/C-series), AMD Radeon GPU (GCN/RDNA 1–3.5), Realtek RTL8723DE WiFi, Realtek Bluetooth, TPM 2.0.

USB & Thunderbolt — xHCI USB 3.0/2.0 driver with polling enumeration. Thunderbolt 3/4 & USB4 driver (all Intel/AMD gens).

WiFi 7 Support — 802.11be WiFi 7 driver supporting Intel BE200, MediaTek MT7927, Qualcomm QCNCM865, Broadcom BCM4389.

2025

Late 2025

Initial Public Release — First public release of Zirvium (v0.1.0) as the reference MOSIX implementation. Kernel boots on bare metal and under QEMU with GRUB2 (Multiboot2) or Limine. Freestanding C library (zirvlibc), init system (zirvinit), interactive shell (zirvshell), 16 system utilities (zirvutils), encrypted display driver (zirvdisplayjet), desktop compositor (zirvui). Website (zirvworld) published with MOSIX standard specification.
