zirvshell is the reference MOSIX interactive shell. It supports English-like natural language syntax alongside standard POSIX command names, making it accessible to new users while remaining familiar to Unix veterans.

Features

  • CWD-aware prompt (/ $)
  • Line editor with backspace
  • Double-quoted argument parsing
  • Multi-word natural language: help me please, clear the screen
  • External commands in /bin/ via execve save/restore — the shell process is preserved and returns to the prompt after every command

Build

make

Produces zirvshell.elf — static, freestanding, no-pie ELF64 linked against zirvlibc.
