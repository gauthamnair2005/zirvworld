Overview

ZirvUI is the native C window manager and desktop compositor for Zirvium. It connects to the DisplayJet kernel driver via syscalls 110–125 and renders a clean, flat desktop environment with cascade-themed window decorations. No Rust dependency — the entire compositor is written in freestanding C11.

Source: github.com/gauthamnair2005/zirvui

The display is 1024×768 pixels at 32 bpp. All rendering is done natively in C into a software framebuffer with vertical blank synchronisation for tear-free display.

Screen Layers (back to front)

  1. Background: Solid colour fill (#3A6EA5 medium blue). No gradients, no particles, no animation.
  2. Windows: Application content framed by the compositor's window chrome (title bar, close button, 1px border). Each window has its own content rendered by a C draw function.

Window Chrome (Cascade Theme)

Every window is framed with a consistent set of decorations applied by the compositor — applications do NOT carry their own themes or chrome:

ElementStyle
Outer border1px black (#000000)
Title bar (active)Solid #4A8AC5 (light blue)
Title bar (inactive)Solid #3A6080 (muted blue)
Title textWhite, centred, 8×13 bitmap font
Close buttonRed square (#CC3333) with white X, highlight on hover
Content backgroundWhite or app-specific

Window Behaviours

  • Drag: Click and drag on the title bar to move the window
  • Close: Click the red close button to dismiss the window
  • Raise: Click anywhere on a window to bring it to the front (z-order)

Compositor Flow

  1. Connect: Call zf_connect() → DisplayJet syscall 110 (register as compositor)
  2. Query mode: Call zf_get_info(&info) → syscall 115
  3. Create buffer: Call zf_create_buffer(w, h, &buf) → syscall 112
  4. Render loop:
    • Clear framebuffer to solid background colour
    • For each visible window (back to front), draw window chrome + content
    • Write framebuffer via zf_write_buffer() → syscall 116
    • Present via zf_present() → syscall 114
    • Poll mouse events via zf_read_mouse() → syscall 122
    • Handle window interactions (move, close, raise)

Drawing Primitives

All rendering uses native C functions in canvas.c operating directly on the 32-bit ARGB framebuffer:

FunctionDescription
canvas_fill_rectSolid rectangle fill with bounds clipping
canvas_fill_gradient_vVertical colour gradient fill
canvas_draw_charBitmap glyph with 4-neighbour edge anti-aliasing
canvas_draw_textNull-terminated text string
canvas_draw_char_scaledScaled bitmap glyph (nearest-neighbour)
canvas_draw_text_largeScaled text at integer scale
canvas_hlineHorizontal line
canvas_fill_circleSolid circle (integer edge-finding fill)
canvas_fill_round_rectSolid rounded rectangle
canvas_draw_lineBresenham line
canvas_blendAlpha-blend two ARGB colours

Font

8×13 pixel bitmap font (95 glyphs, ASCII 32–126) defined in font_8x13.h. Anti-aliased edge rendering uses alpha-blending at 200/255 for non-interior edge pixels (4-neighbour check).

Source Structure

zirvui/
  Makefile                Build system (freestanding ELF, pure C)
  src/
    main.c                Entry point (calls compositor_run)
    compositor.c          Window manager + compositor loop (~340 lines)
    compositor.h          Types and window system API
    canvas.c              Drawing primitives (fill_rect, draw_char, etc.)
    canvas.h              Drawing primitives header
    crt0.asm              Entry point (_start → main → SYS_EXIT)
    font_8x13.h           95×13 bitmap font data

The compositor is entirely self-contained C with no Rust dependency. It links against libzirvflux.a (display framework) and zirvlibc (freestanding libc).

Build

make    # Links canvas.o + compositor.o + main.o + crt0.o + libc + libzirvflux.a

# C flags:
gcc -std=c11 -ffreestanding -fno-stack-protector -fno-pic
    -mno-red-zone -mno-mmx -mno-sse -mno-sse2 -O2
    -I../zirvflux/include

# Link:
ld -nostdlib -static -no-pie -z max-page-size=0x1000 \
    main.o compositor.o canvas.o crt0.o libc/*.o libzirvflux.a

Dependencies

  • zirvlibc (string, ctype, stdio, stdlib, unistd, syscall, datetime)
  • ZirvFlux (libzirvflux.a — display framework library with syscall wrappers)

  • Window resize: Draggable resize handles at window edges
  • Desktop icons: Icon grid on desktop with launch capability
  • TrueType font rendering: Generate and render TTF at runtime
