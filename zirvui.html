Overview

ZirvUI is the graphical desktop compositor / graphical shell for the Zirvium operating system. It connects to the DisplayJet kernel driver via syscalls 110–125 and renders a complete desktop environment into a MAEM-encrypted framebuffer surface. It supports Performance Mode to bypass encryption for a smoother experience, and Smooth Font rendering with anti-aliasing.

The compositor is a user-space process compiled as a freestanding ELF binary (zirvui.elf) linked against zirvlibc and the ZirvFlux API. It can be launched from ZirvShell via run /bin/zirvui.

Source: github.com/gauthamnair2005/zirvui

Elements

  • Background: Procedural per-pixel gradient (horizontal red + vertical green + inverted-horizontal blue channels)
  • Top panel: 28-pixel dark navy bar (0xFF1A1A2E) with 1-pixel accent line
  • Hamburger menu: 3 horizontal lines at top-left (14 px wide)
  • "ZirvUI" branding: Text label next to the hamburger menu
  • System tray (right-aligned): uptime clock, power button, user icon, battery, speaker, WiFi, Bluetooth
  • Uptime clock: MM:SS format rendered with 5x7 bitmap font

Compositor Flow

  1. Connect: Call dj_connect() (syscall 110) to register as compositor
  2. Query mode: Call dj_get_mode(&mode) (syscall 115) to get display resolution (1024x768)
  3. Create surface: Call dj_create_surface(w, h, &surf_id) (syscall 112) — kernel allocates encrypted DMA buffer
  4. Render: Software-render the full desktop into a local 3 MB framebuffer:
    • Pixel-by-pixel background gradient
    • Dark navy panel with all system tray icons
    • Uptime clock string rendered via 5x7 bitmap font
  5. Upload: Call dj_surface_write(surf_id, compositor_fb, size) (syscall 116) — kernel encrypts with ChaCha20, stores in GPU surface
  6. Present: Call dj_present(surf_id) (syscall 114) — kernel decrypts surface to scanout framebuffer
  7. Loop: Repeat rendering and presentation every ~1 second (busy-wait on uptime())

5x7 Bitmap Font

The font is a 96-glyph ASCII set (characters 32–127) stored as a static array:

static const uint8_t font5x7[96][5];

Each glyph is 5 columns wide x 7 rows tall, packed as 5 bytes (one byte per column, bits 0–6 are the rows). Characters are rendered with 1-pixel inter-character spacing (6 px total width).

Rendering logic

static void draw_char(void *fb, uint32_t x, uint32_t y,
                      char c, uint32_t color) {
    if (c < 32 || c > 126) c = '?';
    int idx = c - 32;
    for (int row = 0; row < 7; row++)
        for (int col = 0; col < 5; col++)
            if (font5x7[idx][col] & (1u << row))
                put_pixel(fb, x + col, y + row, color);
}

Text rendering functions

draw_char()Render single glyph at (x, y) position
draw_str()Iterate over string, calling draw_char for each character
draw_int()Convert integer to decimal ASCII and render

Icon Rendering

All system tray icons are rendered procedurally using pixel-level drawing primitives:

IconDrawing methodColour
Power buttonCircle with vertical line (cos/sin lookup)0xFFE74C3C (red)
UserSmall circle (head) + arc (shoulders)PANEL_BLUE
BatteryRectangular outline with fill level (67% hardcoded)Green (>20%) / red (≤20%)
SpeakerRectangle + triangle + sound wave arcsWhite
WiFi3 concentric arc curves at different radiiCyan
BluetoothPixel-art "B" runeDimmed (0xFF555555, disconnected)

Circular icons use 256-entry fixed-point cosine and sine lookup tables (scale factor 100) since there is no libm in the freestanding environment:

static int cos_lookup(int deg) {
    // wraps to 0-359, indexes cos_tab[256]
}
static int sin_lookup(int deg) {
    return cos_lookup(deg - 90);
}

Source Structure

zirvui/
  Makefile                Build system (x86_64-elf cross-compiler)
  src/
    main.c                Compositor main loop, rendering, DisplayJet protocol
    crt0.asm              Entry point (_start → main → SYS_EXIT)

Build

make    # Produces zirvui.elf

# Flags:
CC=x86_64-elf-gcc -std=c11 -ffreestanding -fno-stack-protector
    -fno-pic -mno-red-zone -mno-mmx -mno-sse -mno-sse2 -O2
LD=x86_64-elf-ld -nostdlib -static -no-pie -z max-page-size=0x1000
AS=nasm -f elf64

Dependencies

  • zirvlibc (string, ctype, stdio, stdlib, unistd, syscall, datetime)
