Zirvium is the reference implementation of the MOSIX standard. These projects together form a complete operating system. Each can be used standalone, replaced, or extended to create your own MOSIX distribution.

zirvium

C11 / ASM — GPLv3

The core x86-64 kernel — the reference MOSIX kernel implementation. Implements 4-level paging, bitmap PMM (1 TiB max), higher-half VMM, ELF64 loading, MOSIX VFS, PCI enumeration, and dynamic driver framework. Boots via GRUB2 (Multiboot2) or Limine. 25 syscalls covering file I/O, memory management, process control, time, hostname, system power, and DNS resolution.

Key subsystems: PMM, VMM, kernel heap, process management, ring-buffer IPC, CMOS RTC + TSC uptime, triple console (serial + VGA + framebuffer), ELF loader with 17 embedded binaries, DNS resolver (kernel-level, syscall 102), Linux compat layer (linux_compat.h).

Drivers ported from Linux kernel source via linux_compat.h: NVIDIA GPU, VirtIO block, VirtIO net. These drivers are sourced from the latest Linux kernel tree and adapted to the MOSIX device model with minimal changes.

Build targets: make (kernel ELF), make iso (bootable ISO), make run (QEMU), make vmzirv (kernel-only), make debug (GDB stub).

zirvlibc

C11 — libzirvlibc.a

The reference MOSIX C library — a freestanding libc for MOSIX userspace programs. Provides string.h, ctype.h, stdio.h (printf with %s%d%u%lu%llu%x%p%c%%, zero-padded width), stdlib.h (exit, atoi, atol), unistd.h (read, write, open, close, mmap, brk, execve, getpid, uptime, reboot, shutdown, gethostname, sethostname, getcwd, chdir, getdents), datetime.h, dirent.h, and zirv/syscall.h.

Syscall wrappers via inline assembly (_syscall0 through _syscall6). Unit tests in tests/test_libc.c. Build produces libzirvlibc.a.

zirvinit

C11 / ASM — MOSIX init system (PID 1)

First userspace process. 28 lines of C: prints MOSIX banner, calls execve("/bin/shell", ...). Halts forever if execve fails. Linked against zirvlibc, compiled as static ELF64, embedded as /bin/init.

make -C zirvinit produces zirvinit.elf.

zirvshell

C11 / ASM — MOSIX natural-language shell (438 lines)

The reference MOSIX shell. English-like command syntax alongside standard POSIX aliases. 19 commands including date, settime, timezone, uptime, reboot, shutdown. CWD-aware prompt, line editor with backspace, double-quoted argument parsing, multi-word natural language commands.

make -C zirvshell produces zirvshell.elf, embedded as /bin/shell.

zirvutils

C11 / ASM — 17 MOSIX embedded utilities

Standalone command-line utilities: hello, cat, sysinfo, clear, echo, reboot, shutdown, suspend, poweroff, ping, sleep, true, false, yes, uname, hostname. All statically linked against zirvlibc, compiled as standalone ELF64 binaries, and embedded into the kernel via init_bin.asm.

zirvdisplayjet

C11 — MAEM-encrypted display driver (515 lines)

A MOSIX reference implementation of the MAEM security standard. In-kernel display driver with 11 custom syscalls (110-120): compositor management, surface creation/destruction with ChaCha20 encryption, HKDF-SHA256 key derivation, hardware entropy, crypto wipe, access grants. Drives Bochs VBE at 1024x768x32bpp. All surfaces encrypted at rest.

zirvui

C11 — MOSIX graphical desktop compositor

Reference MOSIX desktop compositor. Connects to DisplayJet for a full desktop: procedural background gradient, 28-pixel top panel (hamburger menu, "ZirvUI" branding), system tray (WiFi, Bluetooth, speaker, battery, user, power icons), live uptime clock in 5x7 bitmap font. Compiled as freestanding ELF64.
