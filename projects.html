zirvium

C11 / ASM — GPLv3

The core x86-64 kernel. Zirvium implements 4-level paging, a bitmap-based physical memory manager, a higher-half virtual memory manager, ELF64 binary loading, a MOSIX-compliant virtual filesystem, full PCI bus enumeration, and a driver framework with support for serial, VGA text mode, pixel framebuffer, SATA (ATA PIO), NVMe, USB storage, PS/2 keyboard and Synaptics touchpad, Intel e1000, VirtIO net and block, Realtek RTL8139, Bochs VGA, VMware SVGA, Intel i915 graphics, and HDA audio.

Key source tree:

  • kernel/main.c — entry point, subsystem init, launch PID 1
  • kernel/mm/pmm.c — physical memory bitmap allocator
  • kernel/mm/vmm.c — 4-level page table management
  • kernel/mm/heap.c — kernel heap (kmalloc/kfree)
  • kernel/proc/process.c — process creation, user mode entry, exit
  • kernel/syscall/syscall.c — syscall dispatch and handlers
  • kernel/ipc/pipe.c — ring-buffer pipes
  • kernel/irq/irq.c — PIC IRQ management
  • kernel/loader/elf.c — static ELF64 loader
  • kernel/loader/embedded.c — embedded binary table
  • fs/vfs.c — MOSIX virtual filesystem
  • arch/x64/boot.asm — Multiboot2 boot stub (32-bit to 64-bit)
  • arch/x64/syscall_entry.asm — SYSCALL/SYSRETQ handler
  • drivers/ — PCI, serial, VGA, fb, SATA, NVMe, USB, PS/2, e1000, virtio, RTL8139, Bochs, VMware, i915, HDA, TPM

Boots via GRUB2 (Multiboot2) or Limine. Produces a bootable ISO with make iso.

zirvlibc

C11 — libzirvlibc.a

A minimal freestanding C library extracted from the Zirvium kernel userspace. Provides the standard C functions needed by MOSIX userspace programs. Syscall numbers follow the MOSIX x86-64 ABI.

Implemented headers

string.h memcpy, memmove, memset, memcmp, strlen, strnlen, strcpy, strncpy, strcmp, strncmp, strchr, strrchr, strstr
ctype.h isspace, isdigit, isalpha, isalnum, toupper, tolower
stdio.h vsnprintf, snprintf, vprintf, printf, puts, putchar — supports %s %d %u %x %p %c %%
stdlib.h exit, abort, atoi, atol — malloc/free/calloc/realloc are stubs returning NULL
unistd.h read, write, open, close, _exit, getpid, brk, sbrk, execve, getcwd, chdir, mmap, munmap
zirv/syscall.h Syscall number definitions (SYS_READ=0 through SYS_CHDIR=80), standard FD constants, error codes

Syscall wrappers

Inline assembly trampolines in src/syscall.c provide _syscall0 through _syscall6. Follows the x86-64 SYSCALL ABI: RAX = number, RDI = arg1, RSI = arg2, RDX = arg3, R10 = arg4, R8 = arg5, R9 = arg6.

Build produces libzirvlibc.a. Unit tests in tests/test_libc.c cover string, ctype, and stdio functions.

zirvinit

C11 / ASM — MOSIX init system (PID 1)

The first userspace process launched by the kernel. A minimal, standalone static ELF binary embedded as /bin/init. Its sole job:

  Z I R V I N I T
  ---------------
  MOSIX Compliant PID 1
  Lead Developer: Gautham Nair

[ INIT ] Starting MOSIX lifecycle...
[ INIT ] Verifying /zirv namespace...
[ INIT ] Launching ZirvShell...

After printing the banner, it calls execve("/bin/shell", ...). If execve fails, it halts forever. The crt0.asm entry calls main, then falls back to SYS_EXIT.

zirvshell

C11 / ASM — MOSIX natural-language shell

The primary user interface for Zirvium OS. Designed with an English-like natural language command syntax. Embedded as /bin/shell.

Commands

echo <text> / say <text>Print text
pwd / wherePrint working directory
unamePrint system name ("Zirvium")
whoamiShow current user ("root")

show system statusDisplay PID and system info
go to <path> / cd <path>Change directory

Features a line editor with backspace support, a CWD-aware prompt (/ $), and argument parsing with double-quote support.
