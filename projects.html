Zirvium is the reference implementation of the MOSIX standard. These projects together form a complete operating system. Each can be used standalone, replaced, or extended to create your own MOSIX distribution.

zirvium

C11 / ASM — GPLv3

The core x86-64 kernel — the reference MOSIX kernel implementation. Implements 4-level paging, bitmap PMM (1 TiB max), higher-half VMM, ELF64 loading, MOSIX VFS, PCI enumeration, and dynamic driver framework. Boots via GRUB2 (Multiboot2) or Limine. 36 syscalls covering file I/O, memory management, process control, time, hostname, system power, IPC, HPC, and DNS resolution.

Key subsystems: PMM, VMM, kernel heap, process management (create, execve save/restore, wait4, zombie reaping), ring-buffer IPC message queues, HPC/MPI primitives (barrier, send/recv, broadcast, reduce), CMOS RTC + TSC uptime, triple console (serial + VGA + framebuffer), ELF loader with 19 embedded binaries, execve save/restore (shell survives after running external commands), DNS resolver (syscall 102), PCI device enumeration exposed to userspace (syscall 103, lspci utility), Linux compat layer (linux_compat.h).

Drivers ported from Linux kernel source via linux_compat.h: NVIDIA GPU (Enveediya), Intel Arc GPU, AMD Radeon GPU, VirtIO block, VirtIO net, RTL8139 NIC, xHCI USB 3.0, Thunderbolt 3/4 & USB4, WiFi 7 (BE200, MT7927, QCNCM865, BCM4389).

Build targets: make (kernel ELF), make iso (bootable ISO), make run (QEMU), make vmzirv (kernel-only), make debug (GDB stub).

zirvlibc

C11 — libzirvlibc.a

The reference MOSIX C library — a freestanding libc for MOSIX userspace programs. Provides string.h, ctype.h, stdio.h (printf with %s%d%u%lu%llu%x%p%c%%, zero-padded width), stdlib.h (exit, atoi, atol), unistd.h (read, write, open, close, mmap, brk, execve, getpid, uptime, reboot, shutdown, gethostname, sethostname, getcwd, chdir, getdents), datetime.h, dirent.h, and zirv/syscall.h.

Syscall wrappers via inline assembly (_syscall0 through _syscall6). Unit tests in tests/test_libc.c. Build produces libzirvlibc.a.

zirvinit

C11 / ASM — MOSIX init system (PID 1)

First userspace process. 28 lines of C: prints MOSIX banner, calls execve("/bin/shell", ...). Halts forever if execve fails. Linked against zirvlibc, compiled as static ELF64, embedded as /bin/init.

make -C zirvinit produces zirvinit.elf.

zirvshell

C11 / ASM — MOSIX natural-language shell

The reference MOSIX shell. English-like command syntax alongside standard POSIX aliases. Built-in commands: echo, pwd, uname, clear, whoami, ls, cat, date, settime, timezone, uptime, reboot, shutdown, poweroff, suspend, cd, mkdir, rm, rmdir, mv, cp, help, exit. External commands in /bin/ are executed via execve with automatic caller save/restore — the shell process is preserved and returns to the prompt after every command. CWD-aware prompt, line editor with backspace, double-quoted argument parsing, multi-word natural language commands.

make -C zirvshell produces zirvshell.elf, embedded as /bin/shell.

zirvutils

C11 / ASM — 18 MOSIX embedded utilities

Standalone command-line utilities: hello, cat, sysinfo, clear, echo, reboot, shutdown, suspend, poweroff, ping, sleep, true, false, yes, uname, hostname, ifconfig, lspci. All statically linked against zirvlibc, compiled as standalone ELF64 binaries, and embedded into the kernel via init_bin.asm.

zirvdisplayjet

C11 — MAEM-encrypted display driver (515 lines)

Reference implementation of the MAEM security standard. In-kernel display driver with 11 syscalls (110-120): compositor management, surface creation/destruction with ChaCha20 encryption, HKDF-SHA256 key derivation, hardware entropy, crypto wipe, access grants. Drives Bochs VBE at 1024x768x32bpp. All surfaces encrypted at rest.

zirvui

C11 — MOSIX graphical desktop compositor (thin stub)

Reference MOSIX desktop compositor. A thin C stub that initialises ZirvFlux, calls ztk_desktop_run() from the ZirvTK Rust toolkit, and blocks. All desktop rendering, widgets, input handling, and the compositor loop are provided by ZirvTK. This allows UI updates to land with only toolkit changes.

zirvflux

C11 — libzirvflux.a

User-space display framework for MOSIX compositors. Provides a Mesa-like API for display enumeration, buffer management, and presentation. Communicates with DisplayJet via syscalls 110–120. All surfaces encrypted at rest.

zirvtk

Rust / C — libzirvtk.a

MOSIX GUI toolkit — a Rust library with C FFI providing a complete desktop compositor, widget set, and software canvas renderer. Includes full compositor loop (Desktop), app launcher, taskbar, anti-aliased clock, particle system, scanline-optimised drawing primitives, glass panels, SVG vector path icons, and 8x13 bitmap font. Builds as libzirvtk.a for freestanding environments.
