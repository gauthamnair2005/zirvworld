Zirvium Desktop

Built from the ground up

Zirvium is an active operating-system milestone with its own kernel, drivers, UI, and system services.

Modern Kernel

Written in Rust and x86-64 assembly with memory management, interrupts, and a clean syscall interface.

DisplayJet Compositor

CPU-rasterized ARGB rendering with damage tracking, font rendering, gradients, and window surfaces.

Clean Desktop UI

Start screen, taskbar, login flow, window management, notifications, and a cohesive design language.

Hardware Support

UEFI GOP, PS/2 input, PCI enumeration, RTC, and a virtio display path for QEMU.

System Apps

Terminal, Files, Monitor, Nodes, Settings, Calculator, Notes, and Network applications.

Performance First

Efficient redraw paths and a small, explicit kernel UI designed to run in QEMU/KVM.
