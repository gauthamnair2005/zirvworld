What is Zirvium?

Zirvium is the reference implementation of the MOSIX (Modern OSIX) operating system standard. Just as GNU/Linux implements POSIX, Zirvium implements the MOSIX specification. It is a from-scratch x86-64 kernel written in C11 and assembly, and serves as both a functional OS and a proving ground for the MOSIX design.

The ecosystem spans fourteen projects: the kernel, a freestanding C library, an init system, an English-like shell, 18 utilities, an encrypted display driver (DisplayJet), a display framework library (ZirvFlux), a Rust GUI toolkit (ZirvTK) with 3D renderer, a native C window manager (ZirvUI) with Cascade-themed window decorations, an audio subsystem with HDA and AC97 drivers, and several hardware driver modules. Together they form a complete operating system capable of booting on bare metal and under QEMU.

The desktop is driven by the ZirvUI C compositor, which connects to DisplayJet via syscalls and renders at 1024x768 with a clean, flat cascade theme — solid background, windows with coloured title bars and close buttons, 1px borders, and full mouse interaction (drag, close, z-order). The compositor is entirely self-contained C with no Rust dependency; all drawing primitives (fill_rect, draw_char, draw_line) are implemented natively in canvas.c. The ZirvTK Rust library provides optional 3D software rendering and utility widgets for external demo programs. All display surfaces are encrypted at rest in kernel memory via the DisplayJet MAEM security layer. The kernel enables SSE/SSE2 for userspace and the ELF loader correctly handles non-page-aligned segments.

But Zirvium is just one MOSIX OS. The MOSIX standard is designed to be implemented by anyone. You can build your own kernel, your own libc, your own shell — and as long as they follow the MOSIX specification, they are part of the MOSIX family. This website is the canonical reference for that specification.

Supported Hardware

Storage: SATA (ATA PIO), NVMe, USB mass storage, VirtIO block (linux compat). Native filesystem: ZirvFS — a Copy-on-Write, content-addressed (SHA-256) filesystem inspired by Git, with adaptive block sizes (4 KiB for USB, 16 KiB for SSD, 64 KiB for HDD), snapshot versioning, and automatic format/mount on all storage devices. Networking: Intel e1000, VirtIO net (linux compat), RTL8139 (linux compat), Realtek RTL8723DE WiFi. Display: Bochs VGA, VMware SVGA II, Intel i915 UHD (Gen 9.5-14), Enveediya GPU (linux compat, nouveau port — RTX/B-series), Intel Arc GPU (linux compat, A/B/C-series), AMD Radeon GPU (linux compat, GCN/RDNA 1-3.5). USB: xHCI USB 3.0/2.0 (linux compat, polling enumeration). Bus: Thunderbolt 3/4, USB4 (linux compat, all Intel/AMD gens). Wireless: WiFi 7 802.11be (linux compat, Intel BE200, MediaTek MT7927, Qualcomm QCNCM865, Broadcom BCM4389). Input: PS/2 keyboard, Synaptics touchpad. Other: HDA audio, Realtek Bluetooth, TPM 2.0, serial 16550 UART. Many drivers ported directly from Linux kernel source via the linux_compat.h compatibility layer.
