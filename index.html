About

Zirvium is a from-scratch x86-64 kernel and operating system that implements the MOSIX (Modern OSIX) standard — a rethinking of POSIX conventions for modern hardware. It replaces legacy paths with a simplified filesystem hierarchy, unifies device management under a single /zirv namespace, and is written entirely in C11 and x86-64 assembly.

The ecosystem spans five projects: the kernel itself, a freestanding C library, an init system, an English-like shell, and a utilities collection. Together they form a complete, functional operating system capable of booting on bare metal and under QEMU.

Ecosystem

five interconnected projects that make up the Zirvium OS

zirvium

C11 / ASM — GPLv3

Core x86-64 kernel with 4-level paging, bitmap PMM, ELF64 loader, MOSIX VFS, PCI enumeration, and drivers for serial, VGA, framebuffer, SATA, NVMe, USB storage, PS/2 input, e1000, virtio, and HDA audio.

  • Multiboot2 + Limine boot
  • SYSCALL/SYSRETQ system calls
  • Process management with address spaces
  • Embedded init and shell binaries
  • Linux-compatible driver API layer

source on github »

zirvlibc

C11 — libzirvlibc.a

Minimal freestanding C library providing string.h, ctype.h, stdio.h (full printf), stdlib.h, unistd.h with Linux-compatible syscall wrappers.

  • Syscall ABI matches Linux x86-64
  • Inline assembly trampolines (0–6 args)
  • Unit-tested string and formatting routines

source on github »

zirvinit

C11 / ASM — MOSIX init system

First userspace process (PID 1). Prints the MOSIX banner, verifies /zirv namespace, and hands control to ZirvShell via execve.

  • Standalone static ELF binary
  • Embedded as /bin/init in kernel
  • Minimal freestanding footprint

part of zirvium tree »

zirvshell

C11 / ASM — MOSIX shell

English-like command shell supporting show system status, go to /bin, help me please. Implements echo, ls, pwd, cd, cat, exec, and more.

  • Line editor with backspace
  • CWD-aware prompt
  • Embedded as /bin/shell in kernel

part of zirvium tree »

zirvutils

placeholder

Intended home for MOSIX-standard command-line utilities (ls, cat, cp, mv, etc.). Project skeleton is in place and awaiting implementation.

Architecture

system layering from boot to userspace

+----------------------------------+
| User Programs                    |
| (zirvinit, zirvshell, ...)       |
+----------------------------------+
          | syscall interface
+----------------------------------+
| zirvlibc                         |
| (printf, read, write, malloc)    |
+----------------------------------+
          | SYSCALL / SYSRETQ
+----------------------------------+
| Zirvium Kernel                   |
| (VFS, procs, drivers, IPC, ELF) |
+----------------------------------+
          | hardware
+----------------------------------+
| x86-64                           |
| (CPU, PCI, SATA, NVMe, USB, ...) |
+----------------------------------+

Key Features

notable capabilities of the Zirvium kernel

Microkernel Architecture
Modular kernel with clean separation between memory management, process control, IPC, and drivers.		 MOSIX VFS
Modern filesystem hierarchy with /bin, /lib, /user, /zirv replacing legacy FHS paths.
Ring-Buffer IPC
Efficient 4 KiB ring-buffer pipes for inter-process communication.		 PCI Enumeration
Full PCI bus scanning with BAR reading and automatic driver-vendor matching.
Triple Console
Simultaneous output to VGA text mode, pixel framebuffer, and serial UART with colour support.		 Embedded Binaries
Init and shell ELF files embedded directly into the kernel binary via incbin.

Quick Start

git clone https://github.com/gauthamnair2005/zirvium.git
cd zirvium
git submodule update --init
make iso
qemu-system-x86_64 -cdrom zirvium.iso

Requires x86-64-elf cross-compiler, nasm, mtools.
