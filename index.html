About

Zirvium is a from-scratch x86-64 kernel and operating system that implements the MOSIX (Modern OSIX) standard. It replaces legacy paths with a simplified filesystem hierarchy, unifies device management under a single /zirv namespace, encrypts display surfaces in memory via MAEM (Memory-Attested Encryption of Surfaces), and provides a full desktop compositor called ZirvUI. The entire system is written in C11 and x86-64 assembly, with no external dependencies.

The ecosystem spans twelve projects: the kernel, a freestanding C library, an init system, an English-like shell, a utilities collection (17 binaries), an encrypted display driver, a graphical desktop compositor, a display manager, and several hardware driver modules. Together they form a complete operating system capable of booting on bare metal and under QEMU, with support for SATA, NVMe, USB storage, Intel e1000, VirtIO, Realtek RTL8139 and RTL8723DE WiFi, Intel i915 graphics, Bochs VGA, VMware SVGA, NVIDIA GPUs, HDA audio, Bluetooth, and TPM 2.0.
