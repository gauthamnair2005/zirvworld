What is Zirvium?

Zirvium is the reference implementation of the MOSIX (Modern OSIX) operating system standard. Just as GNU/Linux implements POSIX, Zirvium implements the MOSIX specification. It is a from-scratch x86-64 kernel written in C11 and assembly, and serves as both a functional OS and a proving ground for the MOSIX design.

The ecosystem spans fourteen projects: the kernel, a freestanding C library, an init system, an English-like shell, 18 utilities, an encrypted display driver (DisplayJet), a display framework library (ZirvFlux), a Rust desktop toolkit (ZirvTK) with full compositor, a graphical desktop compositor (ZirvUI) that delegates to ZirvTK, an audio subsystem with HDA and AC97 drivers, and several hardware driver modules. Together they form a complete operating system capable of booting on bare metal and under QEMU.

The desktop environment is implemented entirely by the ZirvTK Rust library, which provides a complete compositor (ztk_desktop_run) rendering at 1024x768 with a dark/neon/glass aesthetic — gradient background, real-time RTC-driven clock with anti-aliased scaled digits, taskbar with launcher dot button, grid-based app launcher with SVG vector path icons and animated hover pulse (sinusoidal glow), semi-transparent glass panels, ambient floating particles with per-particle colour cycling, and tear-free VBE page-flipped rendering. The ZirvUI compositor is a thin C stub that initialises ZirvFlux and enters the ZirvTK desktop loop. Drawing primitives are scanline-optimised for efficiency. All display surfaces are encrypted at rest in kernel memory via the DisplayJet MAEM security layer. The kernel enables SSE/SSE2 for userspace and the ELF loader correctly handles non-page-aligned segments, enabling the Rust core library to link cleanly in the freestanding compositor.

But Zirvium is just one MOSIX OS. The MOSIX standard is designed to be implemented by anyone. You can build your own kernel, your own libc, your own shell — and as long as they follow the MOSIX specification, they are part of the MOSIX family. This website is the canonical reference for that specification.

Supported Hardware

Storage: SATA (ATA PIO), NVMe, USB mass storage, VirtIO block (linux compat). Networking: Intel e1000, VirtIO net (linux compat), RTL8139 (linux compat), Realtek RTL8723DE WiFi. Display: Bochs VGA, VMware SVGA II, Intel i915 UHD (Gen 9.5-14), Enveediya GPU (linux compat, nouveau port — RTX/B-series), Intel Arc GPU (linux compat, A/B/C-series), AMD Radeon GPU (linux compat, GCN/RDNA 1-3.5). USB: xHCI USB 3.0/2.0 (linux compat, polling enumeration). Bus: Thunderbolt 3/4, USB4 (linux compat, all Intel/AMD gens). Wireless: WiFi 7 802.11be (linux compat, Intel BE200, MediaTek MT7927, Qualcomm QCNCM865, Broadcom BCM4389). Input: PS/2 keyboard, Synaptics touchpad. Other: HDA audio, Realtek Bluetooth, TPM 2.0, serial 16550 UART. Many drivers ported directly from Linux kernel source via the linux_compat.h compatibility layer.
