Quick Start

Requirements

  • x86-64-elf cross-compiler (or gcc with freestanding support)
  • NASM (>= 2.14)
  • GNU Make
  • grub-mkrescue and xorriso (for ISO creation)
  • mtools (for ISO creation)
  • QEMU (for testing)

Build and Run

git clone https://github.com/gauthamnair2005/zirvium.git
cd zirvium
git submodule update --init
make iso
qemu-system-x86_64 -cdrom build/zirvium.iso -serial stdio -m 512M

This will boot the kernel in QEMU with serial console output visible in your terminal.

Build Targets

makeBuild kernel ELF
make isoBuild bootable GRUB2 ISO
make runBuild ISO and launch in QEMU
make debugBuild ISO and launch QEMU with GDB stub on port 1234
make cleanRemove build artefacts

QEMU Run Options

The default make run target launches QEMU with:

  • Serial output redirected to stdio
  • 512 MiB RAM
  • Standard VGA display
  • IDE disk (blank 10 MiB image)
  • VirtIO block device
  • e1000, VirtIO net, and RTL8139 NICs (user-mode networking)

You can adjust the command-line in the Makefile or invoke QEMU directly:

qemu-system-x86_64 -cdrom build/zirvium.iso -serial stdio -m 256M -vga std -display sdl

Directory Structure

zirvium/
  arch/x64/          Architecture-specific code (boot, GDT, IDT, syscall)
  kernel/            Core kernel
    mm/              Memory management (PMM, VMM, heap)
    proc/            Process management
    syscall/         System call handlers
    ipc/             Inter-process communication (pipes)
    irq/             Interrupt handling (PIC)
    loader/          ELF loader, embedded binaries
  fs/                MOSIX Virtual Filesystem
  drivers/           Device drivers
    pci/             PCI bus enumeration
    serial/          16550 UART
    vga/             VGA text mode, framebuffer console
    zirv/            Device namespace drivers
      sata/          ATA PIO
      nvme/          NVMe
      usb_storage/   USB mass storage
      input/ps2/     PS/2 keyboard and Synaptics touchpad
      display/       Bochs VGA, VMware SVGA, Intel i915
      audio/hda/     High-Definition Audio
      wifi/          Realtek RTL8723DE
      bluetooth/     Realtek Bluetooth
      driver.c       Dynamic driver framework
      device.c       Device registry
  libs/zirvlibc/     Freestanding C library
  zirvinit/          Init system (submodule)
  zirvshell/         Shell (submodule)
  zirvutils/         Utilities (submodule, placeholder)
