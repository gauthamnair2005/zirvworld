Quick Start

Requirements

  • x86-64-elf cross-compiler (x86_64-elf-gcc) or system gcc
  • NASM (>= 2.14)
  • GNU Make
  • grub-mkrescue and xorriso (for ISO creation)
  • mtools (for ISO creation)
  • QEMU (>= 6.0, for testing)

Build and Run

git clone https://github.com/gauthamnair2005/zirvium.git
cd zirvium
git submodule update --init --recursive
make run

This single command builds the kernel with all embedded userspace binaries, creates a bootable ISO, and launches QEMU with serial console output visible in your terminal.

Build Targets

makeBuild kernel ELF with embedded userspace binaries
make isoBuild bootable GRUB2/Multiboot2 ISO image
make runBuild ISO and launch in QEMU
make vmzirvBuild kernel-only ELF (no embedded binaries)
make debugBuild ISO and launch QEMU with GDB stub on port 1234
make binStrip the ELF to a flat binary
make cleanRemove all build artefacts

Build Individual Components

make -C zirvinit       # just the init binary (zirvinit.elf)
make -C zirvshell      # just the shell binary (zirvshell.elf)
make -C zirvlibc       # just the C library (libzirvlibc.a)
make -C zirvutils      # all 17 utility binaries

QEMU Run Options

The default make run target launches QEMU with:

  • Serial output redirected to stdio (-serial stdio)
  • 512 MiB RAM (-m 512M)
  • Standard VGA display (-vga std) with SDL window
  • IDE disk (blank 10 MiB image) + VirtIO block device
  • Three NICs: Intel e1000, VirtIO net, Realtek RTL8139 (user-mode networking)
  • -no-reboot to stop on triple fault

Manual invocation:

qemu-system-x86_64 \
    -cdrom build/zirvium.iso \
    -serial stdio \
    -m 256M \
    -vga std \
    -display sdl

Directory Structure

zirvium/
  arch/x64/          Architecture-specific (boot, GDT, IDT, syscall)
  kernel/            Core kernel
    mm/              PMM, VMM, heap
    proc/            Process management
    syscall/         24 syscall handlers
    ipc/             Ring-buffer pipes
    irq/             8259A PIC management
    loader/          ELF loader, embedded binary table
    time/            CMOS RTC, TSC uptime, timezone
  fs/                MOSIX Virtual Filesystem
  drivers/           Device drivers
    pci/             PCI bus + compat layer
    serial/          16550 UART
    vga/             VGA text mode, framebuffer console
    zirv/            Native device drivers
      display/       Bochs VGA, VMware SVGA, Intel i915
      input/ps2/     PS/2 keyboard and Synaptics touchpad
      audio/hda/     High-Definition Audio
      wifi/          Realtek RTL8723DE
      bluetooth/     Realtek Bluetooth
    gpu/             NVIDIA GPU (Linux compat layer)
    compat/          linux_compat.h API bridge
  libs/zirvlibc/     Freestanding C library
  zirvinit/          Init system (submodule)
  zirvshell/         Shell (submodule)
  zirvutils/         17 utilities (submodule)
