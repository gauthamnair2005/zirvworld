Quick Start

Requirements

  • x86-64-elf cross-compiler (x86_64-elf-gcc) or system gcc
  • NASM (>= 2.14)
  • GNU Make
  • grub-mkrescue, xorriso, mtools (for ISO creation)
  • QEMU (>= 6.0, for testing)

Build and Run

git clone https://github.com/gauthamnair2005/zirvium.git
cd zirvium
git submodule update --init --recursive
make run

Build Targets

makeBuild kernel with embedded userspace
make isoBuild GRUB2 bootable ISO
make runBuild ISO and launch in QEMU
make vmzirvKernel-only ELF (no embedded binaries, -DVMZIRV)
make debugLaunch QEMU with GDB stub on port 1234
make cleanRemove all build artefacts

Directory Structure

zirvium/
  arch/x64/          Architecture-specific (boot, GDT, IDT, syscall)
  kernel/            Core kernel (mm, proc, syscall, ipc, irq, loader, time)
  fs/                MOSIX Virtual Filesystem
  drivers/           Device drivers (PCI, serial, VGA, native, compat)
  libs/zirvlibc/     Freestanding C library (submodule)
  zirvinit/          Init system (submodule)
  zirvshell/         Shell (submodule)
  zirvutils/         17 utilities (submodule)
