zirvinit is the reference MOSIX init system — the first userspace process (PID 1) launched by the kernel. It is deliberately minimal: 28 lines of C that print the MOSIX banner and spawn the shell via execve("/bin/shell"). If execve fails (no shell found), it halts forever.

Source

src/crt0.asm     _start -> main -> SYS_EXIT
src/main.c       Banner + execve("/bin/shell")

Build

make

Produces zirvinit.elf — static, freestanding, no-pie ELF64 linked against zirvlibc. Embedded into the kernel as /bin/init.

Design Philosophy

The init process follows the MOSIX philosophy of simplicity and correctness. It does not attempt to manage services, supervise processes, or handle complex boot scenarios. Those responsibilities belong to the shell and userspace tools. Init's sole job is to bring up the shell and keep the system alive as PID 1.

The kernel reaps orphaned processes by reparenting them to init, which automatically collects their exit status via the kernel's wait4 mechanism.
