Boot Sequence

  1. GRUB2 loads the kernel ELF via Multiboot2 protocol and jumps to the 32-bit entry point at 0x100000.
  2. arch/x64/boot.asm: 32-bit stub checks for CPUID and long mode support, builds identity-mapped page tables (4 GiB via 2 MiB huge pages), creates a higher-half kernel map at 0xFFFFFFFF80000000, loads a 64-bit GDT, far-jumps into long mode, and calls kernel_main.
  3. kernel/main.c (14-step init sequence):
    1. serial_init — COM1 at 115200 baud
    2. gdt_init — GDT with null, kernel code/data, user code/data, TSS
    3. idt_init — IDT with 256 ISR entries
    4. irq_init — 8259A PIC remap (IRQ 0-15 → INT 32-47)
    5. Parse Multiboot2 memory map
    6. pmm_init — Physical memory bitmap allocator
    7. vmm_init — 4-level paging with PHYS_MAP_BASE and KERNEL_VIRT_BASE
    8. vga_init — VGA text mode buffer at 0xB8000
    9. console_init — Triple console multiplexer
    10. vfs_init — MOSIX directory tree with /zirv namespace
    11. proc_init — Process table
    12. embedded_init — 17 embedded binary records
    13. syscall_init — LSTAR MSR → syscall_entry
    14. time_init — CMOS RTC + TSC-based uptime
    15. pci_init — Full PCI bus enumeration
    16. driver_probe_all — Dynamic driver probing
    17. i8042_init / keyboard_init — PS/2 keyboard
    18. proc_create(0) — Create PID 1
    19. elf_load_process(PID 1, init) — Load zirvinit.elf
    20. proc_enter_usermode(PID 1) — IRETQ to ring 3

GDT and Segment Layout

File: arch/x64/gdt.c

IndexSegmentDPLPurpose
0Null—Required null descriptor
1Kernel code0CS for ring-0 (L-bit set, 64-bit)
2Kernel data0DS/SS for ring-0
3User code3CS for ring-3 (64-bit)
4User data3DS/SS for ring-3
5TSS0Task State Segment (RSP0 on interrupt)

TSS.RSP0 is updated per-process before entering user mode, so interrupts from ring 3 switch to the correct kernel stack.

Memory Management

Physical Memory Manager (PMM)

File: kernel/mm/pmm.c — Bitmap allocator, 1 bit per 4 KiB page frame, supports up to 1 TiB physical memory (32 MiB bitmap in BSS). The Multiboot2 memory map marks available RAM regions as free; all reserved/ACPI/MMIO regions are marked unavailable. API: pmm_alloc_page, pmm_free_page, pmm_alloc_pages (contiguous), pmm_free_pages.

Virtual Memory Manager (VMM)

File: kernel/mm/vmm.c — x86-64 4-level paging (PML4 → PDP → PD → PT).

0x0000000000000000 - 0x00007FFFFFFFFFFF   User space (per-process)
0xFFFF800000000000                        PHYS_MAP_BASE (direct physical map)
0xFFFFFFFF80000000                        KERNEL_VIRT_BASE (higher-half kernel)

Per-process address spaces clone the upper half (kernel) entries from the kernel PML4 and zero out the lower half. Supports 4 KiB and 2 MiB (huge) pages. The PHYS_TO_VIRT(p) macro converts physical addresses to the direct map.

Kernel Heap

A bump allocator over a 4 MiB static arena (kmalloc, kfree, kzalloc). kfree marks with HEAP_MAGIC_FREE but does not coalesce or reuse. Will be replaced with a slab allocator.

Process Management

Files: kernel/proc/process.c, kernel/proc/process.h

Process descriptor (process_t)

  • PID, state (UNUSED / RUNNING / BLOCKED / ZOMBIE)
  • Per-process address space (address_space_t *as)
  • User RIP/RSP, kernel stack top (16 KiB, PMM-allocated)
  • Heap state: brk at 0x100000000000, mmap_cursor at 0x200000000000
  • Open file descriptor table (64 entries)
  • Parent/child/sibling pointers for process tree tracking
  • Current working directory (cwd[256])

User virtual memory layout

0x0000000000001000                     user code / data (by ELF loader)
0x0000100000000000                     heap base (PROC_HEAP_START)
0x0000200000000000                     anonymous mmap region start
0x0000700000000000                     user stack top (grows downward, 64 KiB)

User mode entry via proc_enter_usermode: sets TSS.RSP0, switches to per-process kernel stack, loads CR3, pushes IRETQ frame (SS, RSP, RFLAGS, CS, RIP), executes IRETQ to ring 3.

Inter-Process Communication

File: kernel/ipc/pipe.c — Ring-buffer pipes with a 4 KiB circular buffer. pipe_read blocks until data is available. pipe_read returns 0 (EOF) when write_closed is true and buffer is empty. Pipe endpoints attach to process file descriptor tables.

Time Subsystem

File: kernel/time/time.c

  • CMOS RTC: BCD/binary, 12h/24h auto-detection
  • TSC-based uptime: CPUID leaf 0x15 for frequency detection (falls back to 2 GHz)
  • time_get / time_set with timezone offset arithmetic
  • time_uptime_seconds returns elapsed wall time since boot
  • time_get_tz / time_set_tz for timezone offset in minutes
  • normalize_datetime handles carry/borrow across all fields
  • Default fallback date: 2005-11-22 15:36 UTC

Interrupts and IRQs

  • 8259A PIC remapped: IRQ 0-15 → IDT vectors 32-47
  • request_irq / free_irq / irq_dispatch / irq_eoi
  • Supports shared IRQs and edge triggering
  • 256 ISR stubs generated in arch/x64/isr_stubs.asm
  • Common ISR dispatch: exceptions (int < 32) panic; hardware IRQs route to registered handlers

Drivers

PCI Subsystem

CF8/CFC I/O port enumeration (256 buses x 32 devices x 8 functions). Full BAR decoding (I/O, memory, 64-bit, prefetchable). pci_map_bar uses PHYS_TO_VIRT for MMIO access. pci_enable_device sets bus master + memory space.

Display

  • Bochs VGA (0x1234:0x1111/0x2111): 1024x768x32, VBE I/O ports
  • VMware SVGA II (0x15AD:0x0405): skeleton
  • Intel i915 (352 lines): Gen 9.5-14 (Kaby Lake through Meteor Lake), ~70 PCI IDs, GMBUS EDID, panel power, backlight PWM
  • NVIDIA GPU (126 lines): Linux compat layer, BAR0+BAR2 mapping, ioctl stubs
  • VGA text mode: 80x25 at 0xB8000, hardware cursor
  • Pixel framebuffer: Glyph renderer for FB console
  • DisplayJet: MAEM-encrypted surfaces, 11 custom syscalls (110-120)

Storage

  • SATA (ATA PIO): IDENTIFY, LBA28 read/write, device type detection
  • NVMe: Polling-mode PCIe SSD driver
  • USB storage: Mass storage stub

Networking

  • Intel e1000 (0x8086:0x100E): probe stub
  • VirtIO net (0x1AF4:0x1000): probe stub
  • Realtek RTL8139 (0x10EC:0x8139): probe stub
  • Realtek RTL8723DE WiFi (355 lines): PCIe, MMIO, DMA rings, efuse MAC, packet TX

Input

  • PS/2 i8042: Controller initialisation
  • PS/2 keyboard: Scancode → ASCII with punctuation mapping
  • Synaptics touchpad: Skeleton

Other

  • Serial: 16550 UART on COM1 at 115200 baud
  • HDA Audio: Intel High-Definition Audio skeleton
  • TPM 2.0: Trusted Platform Module
  • Realtek Bluetooth: UART HCI transport, firmware download skeleton

Dynamic Driver Framework

Two-tier model: (1) native Zirv drivers registered via driver_register with PCI vendor/device ID table, (2) Linux compat drivers via pci_compat_register_driver. The linux_compat.h bridge (610 lines) provides spinlocks, MMIO accessors, DMA API, list operations, timers, and logging macros for porting Linux drivers.

ELF Binary Loader

Files: kernel/loader/elf.c, kernel/loader/embedded.c

Static ELF64 loader: validates header, iterates PT_LOAD program headers, allocates physical pages, maps at ELF-specified VAs, zero-fills BSS. 17 binaries are embedded via NASM incbin (init_bin.asm) including init, shell, and all utilities.
