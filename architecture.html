This is the Zirvium reference architecture. A MOSIX-compliant system may use a different kernel, different libc, or different userspace — as long as it follows the MOSIX specification for the filesystem hierarchy, /zirv device namespace, and syscall ABI.

Boot Sequence

  1. GRUB2 loads kernel via Multiboot2 protocol
  2. arch/x64/boot.asm: 32-bit stub checks CPUID/long mode, builds identity-mapped page tables (4 GiB via 2 MiB huge pages), creates higher-half kernel map at 0xFFFFFFFF80000000, loads 64-bit GDT, far-jumps into long mode
  3. kernel_main: 20-step init sequence — serial, GDT, IDT, PIC, PMM, VMM, VGA, console, VFS, processes, embedded binaries, syscalls, time, PCI, drivers, keyboard, then creates PID 1 and enters user mode

Memory Management

PMM (kernel/mm/pmm.c): Bitmap allocator, 1 bit per 4 KiB frame, supports 1 TiB max. VMM (kernel/mm/vmm.c): 4-level paging. Layout: user space 0x0-0x7FFFFFFFFFFF, PHYS_MAP_BASE 0xFFFF800000000000, KERNEL_VIRT_BASE 0xFFFFFFFF80000000. Per-process address spaces clone kernel upper half. Heap: Bump allocator over 4 MiB arena.

System Calls

25 syscalls (0–103), dispatched via SYSCALL/SYSRETQ. Notable additions: SYS_EXECVE (59) implements save/restore semantics — the caller's address space is preserved and restored when the child exits, enabling the shell to run external commands without forking. SYS_PCI_READ (103) exposes PCI device info to userspace. SYS_DNS_LOOKUP (102) provides kernel-level DNS resolution. Full table in the MOSIX standard specification.

Drivers

Display: Bochs VGA, VMware SVGA II, Intel i915 (Gen 9.5-14, 70 PCI IDs, 352 lines), Enveediya GPU (Linux compat, nouveau port — RTX/B-series), Intel Arc GPU (Linux compat, A/B/C-series), AMD Radeon GPU (Linux compat, GCN/RDNA 1-3.5), DisplayJet (MAEM encrypted, 515 lines). Storage: SATA (ATA PIO), NVMe, USB mass storage, VirtIO block (Linux compat). Networking: Intel e1000, VirtIO net (Linux compat), RTL8139 (Linux compat), Realtek RTL8723DE WiFi (355 lines, PCIe, DMA rings, efuse MAC, packet TX), WiFi 7 802.11be (Linux compat, Intel BE200, MediaTek MT7927, Qualcomm QCNCM865). USB: xHCI USB 3.0/2.0 (Linux compat, polling mode, device enumeration). Bus: Thunderbolt 3/4, USB4 (Linux compat, Intel/AMD). Input: PS/2 i8042, keyboard (scancode to ASCII), Synaptics touchpad. Other: HDA audio, Realtek Bluetooth (UART HCI), TPM 2.0, serial 16550 UART, Linux compat driver bridge.

Linux Compat Driver Porting. The linux_compat.h header provides a 610-line compatibility layer that lets Linux kernel source compile under the MOSIX kernel with minimal changes. Currently ported drivers: Enveediya GPU (drivers/gpu/enveediya/), Intel Arc GPU (drivers/gpu/arc/), AMD Radeon GPU (drivers/gpu/radeon/), VirtIO block (drivers/virtio/), VirtIO net (drivers/virtio/), RTL8139 (drivers/net/rtl8139/), xHCI USB 3.0 (drivers/usb/xhci/), Thunderbolt/USB4 (drivers/thunderbolt/), WiFi 7 (drivers/net/wifi7/). These include ring management, PCI transport, device enumeration, and device-specific logic sourced from the latest Linux kernel tree.
