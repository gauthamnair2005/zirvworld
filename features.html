Features

The desktop features currently implemented in the Zirvium milestone.

Start screen

Full-screen app tiles, search styling, live system information, animated opening, and session controls.

Taskbar

Clean, minimal taskbar with app launching and window management.

Window Manager

Resizable, draggable windows with focus management.

System apps

Terminal, Files, Monitor, Nodes, Settings, Calculator, Notes, and Network.

Settings

Change theme mode, accent, Start color, wallpaper, clock seconds, animations, and the desktop grid.

Boot & session

Black Zirvium boot splash, custom loading dots, liveuser sign-in, and log out back to the login screen.
