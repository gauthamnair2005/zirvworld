The MOSIX ecosystem is open to contributions at every level. Whether you want to improve the reference implementation (Zirvium) or build your own MOSIX distribution, there are many ways to get involved.

Ways to Contribute

1. Improve Zirvium (Reference Kernel)

The Zirvium kernel is the reference MOSIX implementation. Key areas needing work:

  • Scheduler: Implement preemptive multitasking (timer IRQ, context switching)
  • SMP: Multi-CPU support (per-CPU stacks, TSS, syscall entry)
  • Storage: AHCI driver, filesystem driver (FAT, ext2, or custom MOSIX FS)
  • Networking: TCP/IP stack, socket syscalls
  • Drivers: More hardware support via the linux_compat.h bridge
  • Userspace heap: Proper malloc/free using brk and mmap
  • Shell pipes: Implement | and > redirection in zirvshell

2. Improve the Website & Specification

The zirvworld repository contains both the website and the MOSIX specification. Improvements welcome: better documentation, diagrams, tutorials, or clarifications of the standard.

3. Build a MOSIX Distribution

Follow the distribution guide to create your own MOSIX OS. This could be:

  • A minimal embedded MOSIX for IoT or single-purpose devices
  • A desktop MOSIX with a custom compositor, window manager, and applications
  • A research MOSIX experimenting with new kernel designs while maintaining MOSIX ABI compatibility
  • A port of MOSIX to a new architecture (ARM, RISC-V, etc.)

4. Write Userspace Programs

MOSIX needs applications. The userspace guide explains how to write programs using zirvlibc. Ideas: text editor, file manager, games, developer tools.

5. Port Linux Drivers

The linux_compat.h bridge makes it possible to port existing Linux drivers to Zirvium with minimal changes. The WiFi and NVIDIA GPU drivers demonstrate this approach.

How to Submit

All MOSIX projects use GitHub:

  • Bug reports and feature requests: Open an issue on the relevant repository
  • Code contributions: Fork, make changes, submit a pull request
  • Documentation: PRs against zirvworld
  • New distributions: We'd love to feature your MOSIX distribution on this site — open an issue or PR on zirvworld

All code is GPLv3. By contributing, you agree to license your contributions under GPLv3.
